# AI 应用开发实习岗位能力画像

核心要求：
- 熟悉 Python、FastAPI 或同类 Web 框架，能封装稳定的模型调用接口。
- 理解 LLM 应用开发链路，包括 Prompt 设计、结构化输出、异常兜底、超时重试和成本控制。
- 具备 RAG 经验，理解文档切分、Embedding、向量检索、召回质量、引用证据和结果校验。
- 能解释 Agent 工作流，说明多角色协作、工具调用、状态管理和失败降级策略。

项目证据建议：
- 说明知识库数据来源、chunk 策略、embedding 模型、向量数据库和检索排序方式。
- 给出模型输出质量控制方案，例如 JSON Schema 校验、二次校验、证据链和人工可编辑结果。
- 尽量量化效果，例如响应耗时、命中率、通过率、节省修改时间或用户反馈。
