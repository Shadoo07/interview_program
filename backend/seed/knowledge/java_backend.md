# Java 后端开发实习岗位能力画像

核心要求：
- 熟悉 Java 基础、集合、异常、泛型、线程池、JVM 基础和常见并发问题。
- 熟悉 Spring Boot、MyBatis / JPA、RESTful API、参数校验、统一异常处理和日志。
- 理解 MySQL 表设计、索引、事务、慢查询分析，以及 Redis 缓存、过期策略和缓存一致性。
- 加分项包括消息队列、分布式锁、接口幂等、限流降级、Docker 部署和简单监控。

项目证据建议：
- 项目经历应说明业务链路，而不是只列 CRUD。
- 如果使用 Redis，需要说明缓存什么数据、如何设置过期、如何避免缓存穿透或不一致。
- 如果涉及订单、报名、支付等场景，需要说明事务一致性、幂等和并发处理方案。
