# 优秀简历表达模板

项目经历推荐结构：
- 背景：说明项目要解决的问题、服务对象和业务目标。
- 职责：明确“我负责什么”，避免只写团队整体成果。
- 行动：说明技术方案、架构设计、关键模块和难点解决过程。
- 结果：尽量量化性能、效率、规模、准确率、用户量或业务指标。

优秀表达示例：
- 设计并实现基于 FastAPI 的简历解析与诊断接口，封装文件上传、文本抽取、LLM 结构化输出和异常兜底流程，使分析链路具备可复用能力。
- 构建 RAG 知识库检索模块，完成文档切分、Embedding 生成、向量检索和引用证据注入，提升岗位建议的针对性。
- 将原本泛泛的项目描述改写为“使用什么技术，解决什么问题，产生什么结果”，并补充可验证指标。

常见问题：
- “参与开发系统”表达太弱，应改成“负责某模块/设计某方案/优化某指标”。
- “熟悉某技术”缺少证据，应结合项目场景说明如何使用。
- 项目没有结果指标时，可补充规模、复杂度、约束条件或复盘收益。
