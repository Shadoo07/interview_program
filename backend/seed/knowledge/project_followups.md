# 项目深挖追问案例

通用项目追问：
- 这个项目解决了什么具体问题？为什么值得做？
- 你在项目中负责哪一部分？哪些是你独立完成的？
- 你为什么选择这个技术方案？有没有比较过其他方案？
- 项目中最大的技术难点是什么？你如何定位和解决？
- 如果重新做一次，你会如何改进架构、性能或用户体验？

后端项目追问：
- 接口如何设计？如何做参数校验、异常处理和日志追踪？
- 数据库表结构如何设计？索引为什么这样建？
- Redis 用在什么场景？如何处理缓存击穿、穿透和一致性？
- 如何保证接口幂等？并发请求下会不会产生脏数据？

AI 应用项目追问：
- Prompt 如何设计？如何保证模型输出 JSON 稳定？
- RAG 的文档如何切分？召回不准时如何排查？
- 如何控制模型幻觉？是否有二次校验或引用证据？
- 多模型切换时如何统一接口、处理超时和失败兜底？
