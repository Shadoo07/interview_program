# 前端开发实习岗位能力画像

核心要求：
- 熟悉 HTML、CSS、JavaScript、TypeScript 和 Vue3 / React 至少一种主流框架。
- 能完成组件拆分、状态管理、路由设计、接口联调、错误处理和响应式布局。
- 了解前端工程化，包括 Vite / Webpack、代码分割、打包体积优化、环境变量和部署流程。
- 能从用户体验角度优化交互，关注加载速度、视觉层级、表单反馈和边界状态。

项目证据建议：
- 描述复杂组件、状态流转、接口联调、权限控制或图表可视化等具体场景。
- 给出性能优化证据，例如首屏加载、包体积、接口等待、重复渲染或资源懒加载。
- 简历表达中避免只写“完成页面”，应写清楚业务问题、技术方案和个人贡献。
